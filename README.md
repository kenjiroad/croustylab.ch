# croustylab.ch

Site de Crousty Lab — Rue de Lyon 14, 1201 Genève.

Site statique, sans build : GitHub Pages publie ce dossier tel quel, sur le domaine du fichier `CNAME`.
`netlify.toml` ne sert que si le site passe un jour chez Netlify.

Ce dossier est **généré** par `build/exporter-site.sh` depuis `00-RESSOURCES/9-SITE/v2-anime/`.
Pour modifier le site : modifier `v2-anime/`, relancer le script, puis pousser.
